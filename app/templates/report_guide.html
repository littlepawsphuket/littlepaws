คู่มือการใช้งาน

เปิดเว็บบน Mac หรือใช้ iPad และมือถือที่ต่อ Wi‑Fi เดียวกันกับ Mac เปิดภาพประกอบเพื่อดูขนาดเต็มได้

แดชบอร์ดลูกค้าและสุนัขการจอง เข้าพักและรับกลับรับชำระและออกเอกสารรายงานและตั้งค่า

แดชบอร์ด

ดูสุนัขที่กำลังเข้าพัก วันรับกลับ และการจองที่รอเช็กอิน แตะ ดูการจอง เพื่อเปิดรายละเอียด หรือแตะ เช็กอิน เพื่อเริ่มรับฝากจากการจองนั้น เลือกช่วงเดือนเพื่อดูแนวโน้มรายรับและรายจ่าย

{{ photo('dashboard','แดชบอร์ดและการ์ดสุนัขที่มีกำหนดเข้าพัก') }}

ลูกค้าและสุนัข

  1. เปิด ลูกค้า แล้วพิมพ์ชื่อในช่องเลือกลูกค้า หรือเพิ่มลูกค้าใหม่
  2. เพิ่มสุนัขในโปรไฟล์ลูกค้า ใส่ขนาด ข้อมูลสุขภาพ วันเกิดหรืออายุ และเลือกรูปจากเครื่องหรือถ่ายด้วยกล้อง
  3. เปิดประวัติการเข้าพักเพื่อดูการใช้บริการของสุนัขทุกตัวของลูกค้ารายนั้น หากมียอดค้าง ให้แตะยอดเพื่อเปิดหน้ารับชำระ
{{ photo('customers','เมนูลูกค้าและฟอร์มเพิ่มข้อมูลลูกค้า') }}

การจองและมัดจำ

  1. เปิด การจอง แล้วกดไอคอนเพิ่ม เลือกลูกค้า สุนัข ประเภทบริการ วันเข้าพักและวันรับกลับ ตรวจราคาก่อนบันทึก
  2. เมื่อพบวันหยุด การจองซ้ำ หรือเกินความจุ ให้ตรวจคำเตือนและยืนยันหากต้องการบันทึกต่อ
  3. เปิดหน้าดูการจองเพื่อแก้ไขข้อมูล ออกใบยืนยัน หรือเพิ่มรายการมัดจำตามยอด วัน และเวลาที่รับจริง ออกใบรับมัดจำของแต่ละรายการเป็น PDF หรือรูปภาพได้
{{ photo('bookings','ปฏิทินการจองและปุ่มเพิ่มการจอง') }}

เช็กอิน ดูแล และรับกลับ

  1. เริ่มจากปุ่ม เช็กอิน ในการจองเดิม หรือเปิด ฝากเลี้ยง สำหรับลูกค้าที่มาโดยตรง เพิ่มหรือแก้ไขข้อมูลลูกค้าและสุนัขจากฟอร์มได้
  2. ตรวจวันเวลา ราคา ส่วนลดหรือคูปอง และยอดรับจริง กรอกของใช้และผลตรวจร่างกายตามที่จำเป็น ให้ลูกค้าติ๊กรับทราบเงื่อนไขและเซ็นก่อนบันทึก
  3. ระหว่างเข้าพัก เปิด การดูแลวันนี้ ในการ์ดบนแดชบอร์ดเพื่อบันทึกให้อาหารหรือให้ยา เมื่อน้องกลับบ้าน กด เช็กเอาต์ แล้วยืนยัน
{{ photo('checkin','ฟอร์มฝากเลี้ยงสำหรับเลือกลูกค้า ประเภทบริการ และวันเวลา') }}

รับชำระและออกเอกสาร

หลังบันทึกการรับฝาก ให้เปิดหน้าสรุปเพื่อดูยอดสุทธิ มัดจำ ยอดที่รับแล้ว และยอดค้าง ใช้ QR สำหรับโอนหรือบันทึกรับเงินเพิ่มเมื่อได้รับจริง หากลบรายการรับชำระให้ระบุเหตุผล

ใช้ปุ่ม PDF หรือรูปภาพภาษาไทยหรืออังกฤษเพื่อส่งเอกสารให้ลูกค้า หากยกเลิกการเข้าพัก ให้ระบุเหตุผลในหน้าสรุป และบันทึกการคืนเงินแยกเมื่อคืนเงินจริง

รายรับ–รายจ่าย รายงาน และตั้งค่า

  • ตั้งค่าระบบ → รายรับ–รายจ่าย ใช้บันทึกธุรกรรมทั่วไปพร้อมหมวดและใบเสร็จ และกรองตามประเภทหรือช่วงวันที่
  • ตั้งค่าระบบ → รายงาน เลือกรายงานและช่วงเวลา แล้วส่งออก Excel, PDF หรือรูปภาพ
  • ตั้งค่าระบบ ใช้ตั้งราคาตามประเภทและขนาด กำหนดวันหยุด ความจุ เปลี่ยนธีม และจัดการคูปอง
{{ photo('reports','ตัวกรองช่วงเวลาและตัวเลือกส่งออกรายงาน') }}

คู่มือสำรองและกู้คืน

ดาวน์โหลด ZIPทดสอบกู้คืนกู้คืนจริงบน Mac

ดาวน์โหลดชุดสำรอง

  1. เปิด ตั้งค่าระบบ → สำรองข้อมูล
  2. กด ดาวน์โหลด ZIP ฐานข้อมูลและใบเสร็จ แล้วตรวจว่าไฟล์ดาวน์โหลดครบ
  3. เก็บไฟล์ ZIP ไว้ในที่ที่เข้าถึงได้เมื่อต้องกู้เครื่อง และจำกัดสิทธิ์เข้าถึงเพราะไฟล์มีข้อมูลลูกค้า
{{ photo('backup','หน้าสำรองข้อมูลพร้อมปุ่มดาวน์โหลดและทดสอบกู้คืน') }}

ทดสอบกู้คืนกับสำเนา

  1. เลือกไฟล์ ZIP ที่เพิ่งดาวน์โหลดในช่อง ไฟล์สำรอง ZIP
  2. กด ทดสอบกู้คืนกับสำเนา รอข้อความยืนยันและจำนวนไฟล์ใบเสร็จที่ตรวจพบ การทดสอบจะใช้พื้นที่ชั่วคราว
  3. หากทดสอบไม่ผ่าน ให้ดาวน์โหลดชุดสำรองใหม่หรือเลือกชุดอื่นที่ทดสอบผ่านก่อนกู้คืนจริง
{{ photo('verified','ข้อความยืนยันเมื่อทดสอบกู้คืนกับสำเนาสำเร็จ') }}

กู้คืนจริงบน Mac

การกู้คืนจริงจะนำข้อมูลใน ZIP กลับมาเป็นข้อมูลที่ระบบใช้งาน ให้ดาวน์โหลดชุดสำรองของข้อมูลปัจจุบันก่อน แล้วทำขั้นตอนต่อไปนี้ใน Terminal บน Mac

  1. เปลี่ยน ชื่อไฟล์.zip ให้ตรงกับไฟล์จริง หากไฟล์อยู่นอก Downloads ให้เปลี่ยนตำแหน่งด้วย
  2. ใช้สองบรรทัดแรกเพื่อตรวจและแตก ZIP ลงโฟลเดอร์ใหม่ หากตรวจไม่ผ่านให้หยุดที่ขั้นนี้ หากชื่อ restore-staging มีอยู่แล้ว ให้ใช้ชื่อใหม่ทั้งในคำสั่งตรวจและคำสั่งย้าย
  3. เมื่อเห็นข้อความ Verified database ให้รันคำสั่งส่วนที่เหลือทีละบรรทัด แล้วเปิดเว็บเพื่อตรวจรายการ ลูกค้า การเข้าพัก และใบเสร็จ
cd "$HOME/Library/Application Support/Little Paws Finance"
.venv/bin/python -m app.backup_archive "$HOME/Downloads/ชื่อไฟล์.zip" restore-staging
./stop-macos.command
mv data "data-before-restore-$(date +%Y%m%d-%H%M%S)"
mv restore-staging data
./start-macos.command

ย้อนกลับเมื่อพบปัญหา ปิดระบบ ย้ายโฟลเดอร์ data ที่เพิ่งกู้ไปอีกชื่อ เปลี่ยนชื่อโฟลเดอร์ data-before-restore-… ที่สร้างในรอบนี้กลับเป็น data แล้วเปิดระบบอีกครั้ง
