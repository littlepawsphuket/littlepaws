# 🐾 Little Paws Finance Manager

Cloudflare migration status and test commands are in [cloudflare/README.md](cloudflare/README.md). The Cloudflare staging deployment includes customer timelines and an Access-protected staff workspace. The full application continues to run via Flask on macOS.

For installations from GitHub, copy the original payment QR privately to `data/payment-qr.jpg` (or the configured `LITTLE_PAWS_DATA` location). The app serves it to signed-in users. Guide screenshots are optional installation files and the text guide works without them.

เว็บแอปบันทึกรายรับ–รายจ่ายและการเข้าพักของ Little Paws Homestay Phuket สำหรับ macOS และมือถือใน Wi‑Fi เดียวกัน

## ความสามารถ
- Dashboard เลือกเดือน: รายรับ คืนเงิน รายจ่าย กระแสเงินสดสุทธิ กราฟ 6 เดือน หมวดค่าใช้จ่าย และสถิติการเข้าพัก
- รายชื่อลูกค้า / สุนัข (หนึ่งลูกค้ามีสุนัขได้หลายตัว)
- การเข้าพักหนึ่งรายการเลือกสุนัขได้หลายตัว มีสถานะ วันเข้าพัก วันรับกลับ จำนวนคืนที่คิดเงิน และค่าฝากตามตกลง
- รับเงิน คืนเงิน รายจ่าย แยกตามวันที่เงินเคลื่อนไหวจริง แนบใบเสร็จ/สลิป และแก้ไข/ลบรายการ
- Export CSV และดาวน์โหลดสำรองฐานข้อมูล SQLite
- เปิดจาก Mac เครื่องนี้โดยตรงและป้องกัน CSRF สำหรับแบบฟอร์ม

> **สำคัญ:** สถิติการเข้าพักอิงเดือนของวันเช็กอิน แต่สถิติการเงินอิงวันที่รับหรือจ่ายเงินจริง จึงอาจต่างกันได้ การเงินเป็นกระแสเงินสด ไม่ใช่งบกำไรขาดทุนทางบัญชี

## เปิดและปิดระบบบน Mac เครื่องนี้

- เปิดด้วย `start-macos.command` แล้วเข้า http://localhost:8000 เว็บทำงานเป็นบริการของ macOS ต่อได้หลังปิด Terminal หรือแชต
- ปิดด้วย `stop-macos.command` เมื่อลงชื่อเข้าบัญชี Mac ใหม่หรือรีสตาร์ต ให้เปิดเว็บอีกครั้งด้วยไฟล์เริ่มระบบ
- ถ้าเปิดไฟล์จาก Finder ไม่ได้ ให้พิมพ์ `/bin/zsh ` ใน Terminal แล้วลากไฟล์ `.command` ลงในหน้าต่างและกด Enter
- ระบบที่ใช้งานจริงอยู่ใน `~/Library/Application Support/Little Paws Finance` ฐานข้อมูลและใบเสร็จอยู่ใน `data/` ภายในตำแหน่งเดียวกัน โฟลเดอร์นี้ใน Documents เก็บสำเนาฐานข้อมูลก่อนย้าย

## เปิดจากมือถือหรือแท็บเล็ตใน Wi-Fi บ้าน

เชื่อมต่อ Wi-Fi บ้านวงเดียวกับ Mac แล้วเปิด URL บรรทัด Wi-Fi ที่แสดงเมื่อรัน `start-macos.command` ปัจจุบันคือ http://192.168.1.55:8000 เว็บเปิดให้เครื่องในวง `192.168.1.0/24` ใช้งานโดยตรง Mac ต้องเปิดระบบและตื่นอยู่ หาก IP เปลี่ยน ให้ปิดและเปิดระบบใหม่เพื่อดู URL ล่าสุด

## การติดตั้งใหม่

ใช้ Python 3.10 ขึ้นไป สร้างสภาพแวดล้อมด้วย `python3 -m venv .venv` และติดตั้งด้วย `.venv/bin/python -m pip install -r requirements.txt` เก็บไฟล์ `.env.local` และโฟลเดอร์ `data/` เดิมเมื่อย้ายหรือติดตั้งซ้ำ หากเป็นการติดตั้งใหม่ทั้งหมด ให้สร้าง `.env.local` ด้วยสิทธิ์ 600 และกำหนด `SECRET_KEY` เป็นค่าสุ่ม ใส่ `PORT=8000` เปิดระบบครั้งแรกเพื่อสร้างตาราง SQLite

## วิธีเริ่มใช้งาน

1. ไปที่ **ลูกค้า** → เพิ่มลูกค้า → กดชื่อลูกค้า → เพิ่มสุนัข
2. ไปที่ **ฝากเลี้ยง** → เลือกลูกค้าและสุนัข → วันเข้าพัก วันรับกลับ จำนวนคืน และค่าฝากที่ตกลง
3. ไปที่ **รายรับ–รายจ่าย** → เพิ่มการรับเงิน/คืนเงิน/รายจ่าย โดยเลือกวันที่เงินจริง และผูกกับการเข้าพัก (ถ้ามี)
4. ไปที่ **Dashboard** → เลือกเดือนที่ต้องการดู

**หมายเหตุ:** ยอดค่าฝากในรายการเข้าพักเป็นข้อมูลอ้างอิง **ไม่ถูกนับเป็นรายรับอัตโนมัติ** จนกว่าจะบันทึกรายการรับเงินจริง เพื่อป้องกันการนับซ้ำเมื่อรับมัดจำหรือจ่ายหลายงวด

## ข้อมูลและสำรอง

- SQLite: `data/little_paws.sqlite3` (สร้างอัตโนมัติ)
- สลิป: `data/receipts/`
- กดปุ่ม **สำรองฐานข้อมูล** ที่ Dashboard เพื่อดาวน์โหลด snapshot ของ SQLite
- สำรอง **ทั้งโฟลเดอร์ `data/`** เป็นประจำ เพื่อเก็บทั้งฐานข้อมูลและไฟล์สลิป
- การกู้คืน: ปิดแอปก่อน คัดลอกไฟล์ `.sqlite3` สำรองทับ `data/little_paws.sqlite3` (และนำโฟลเดอร์ receipts ที่สำรองไว้กลับมา) จากนั้นเริ่มระบบใหม่
- หากย้ายเครื่อง ให้คัดลอกทั้งโฟลเดอร์แอปพร้อม `data/` และ `.env.local` ไปยัง Mac เครื่องใหม่
- ไฟล์ `.env.local`, `data/` และ `.venv/` **ห้ามอัปโหลดไปยัง public Git repository**

## Google Sheets ต้นแบบ

โครงสร้างอิงแนวคิดจากไฟล์ Google Sheets ที่ให้ไว้: รายรับตามวันที่เงินจริง, คืนเงิน, ข้อมูลลูกค้า/สุนัข/การเข้าพัก, รายจ่ายและหมวดหมู่ **ระบบไม่ได้แก้ไขหรือเชื่อมซิงก์ไฟล์ Google Sheets ต้นฉบับ** และไม่ได้โหลดข้อมูลส่วนตัวจาก Sheet เข้าแอปโดยอัตโนมัติ

## ข้อจำกัดเวอร์ชันแรก

- ใช้งานผ่าน Mac เครื่องนี้และเครือข่าย Wi-Fi บ้านที่ตั้งไว้
- ยังไม่มีระบบนำเข้าข้อมูล Sheets อัตโนมัติ, OCR สลิป, การแก้ไขการเข้าพักย้อนหลัง หรือการแก้ไขไฟล์แนบเดิม
- Dashboard แสดงยอดตามเงินจริงและสถิติการเข้าพักเดือนเช็กอิน (ไม่คำนวณ occupancy rate ตามจำนวนห้อง/พื้นที่)
- ข้อมูลการจอง/เข้าพักและธุรกรรมเป็นคนละชุด ต้องบันทึกรับเงินจริงแยกกัน
- หากต้องการใช้งานผ่านอินเทอร์เน็ตหรือเก็บข้อมูลลูกค้าในวงกว้าง ควรเพิ่ม HTTPS, การจัดการสิทธิ์, audit log และนโยบายข้อมูลส่วนบุคคลก่อน

## แก้ปัญหา

- `python3: command not found` → ติดตั้ง Python
- `Address already in use` → เปลี่ยน `PORT` ใน `.env.local` เป็น 8001 แล้วใช้ URL port 8001
- หน้าเว็บไม่เปิดบน iPhone → เช็ก IP ของ Mac, Wi‑Fi เดียวกัน, firewall และ sleep mode

### สำรองและกู้คืน

เปิด **ตั้งค่าระบบ → สำรองข้อมูล** เพื่อดาวน์โหลด ZIP ที่มีฐานข้อมูล ใบเสร็จ และไฟล์ QR ชำระเงินต้นฉบับ (ถ้ามี)
เลือก ZIP ใน **ทดสอบกู้คืนกับสำเนา** เพื่อตรวจฐานข้อมูลและไฟล์ใบเสร็จในพื้นที่ชั่วคราว

หากต้องกู้คืนจริงบน Mac ให้ทำตอนปิดระบบและเก็บโฟลเดอร์ข้อมูลก่อนกู้ไว้
แทนที่ชื่อ ZIP ในตัวอย่างด้วยชื่อไฟล์ที่ดาวน์โหลด และใช้ชื่อโฟลเดอร์ staging ที่ยังไม่มี

```bash
cd "$HOME/Library/Application Support/Little Paws Finance"
.venv/bin/python -m app.backup_archive "$HOME/Downloads/ชื่อไฟล์.zip" restore-staging
./stop-macos.command
mv data "data-before-restore-$(date +%Y%m%d-%H%M%S)"
mv restore-staging data
./start-macos.command
```

ถ้าตรวจ ZIP ไม่ผ่าน ให้หยุดที่ขั้นตรวจไฟล์ ถ้าเปิดระบบหลังการกู้แล้วพบปัญหา
ให้ปิดระบบ ย้ายโฟลเดอร์ `data` ที่กู้ไว้ไปอีกชื่อ แล้วเปลี่ยนชื่อโฟลเดอร์ `data-before-restore-...` กลับเป็น `data` ก่อนเปิดระบบ
